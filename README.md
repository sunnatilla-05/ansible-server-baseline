# ansible-server-baseline

Ansible-плейбук для приведения чистого Ubuntu/Debian-сервера к базовому безопасному состоянию.
Подходит для домашней лаборатории (Ubuntu Server в VirtualBox) и новых окружений.

## Что делает

| Роль            | Действия                                                                  |
|-----------------|---------------------------------------------------------------------------|
| `base`          | обновляет кэш пакетов, ставит утилиты, включает UFW и fail2ban            |
| `ssh_hardening` | запрещает вход root и по паролю, ограничивает число попыток входа        |
| `nginx`         | ставит nginx, применяет шаблон конфигурации, добавляет `/healthz`        |

Плейбук идемпотентен: повторный запуск ничего не меняет, если сервер уже в нужном состоянии.

## Запуск

```bash
ansible-galaxy collection install community.general
# впишите адрес сервера в inventory.ini
ansible-playbook site.yml --check --diff   # сухой прогон
ansible-playbook site.yml
```

Перед применением роли `ssh_hardening` проверьте, что вход по ключу работает.

## Идеи для развития

- Роль для установки Docker.
- Роль с `node_exporter` для сбора метрик Prometheus.
- Проверка ролей через `ansible-lint` и Molecule в CI.
